# College Resource Management System

A beginner-friendly C++ project designed to help college students organize and access their study resources in one place.

## Problem Statement

College study materials are often scattered across WhatsApp groups, Google Drive, and different platforms. This makes it difficult for students to find the resources they need.

## Solution

The College Resource Management System provides a simple, centralized way to organize and manage educational resources.

## Features

- Add new study resources
- View all saved resources
- Search resources by title or category
- Organize resources into categories
- Save and load resource information using file handling

## Technologies Used

- C++
- Standard Template Library (STL)
- File handling (`ifstream`, `ofstream`)
- Structures, arrays, functions, and loops

## How to Run

1. Clone or download this repository.
2. Install a C++ compiler such as GCC.
3. Open a terminal in the project directory.
4. Compile the program:

   ```bash
   g++ main.cpp -o resource_manager
